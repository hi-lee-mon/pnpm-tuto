importしただけでライブラリよりも外の世界に影響を与えるものです。

例えば、style.cssはパッケージのグローバルに適用されるものです。つまりButton.tsxとTextfield.tsxの両方が依存しています。
しかし、Buttonコンポーネントで何を書いてもButtonコンポーネントにしか影響がありません。

package.jsonにでside effectを指定します。
```ts
  "sideEffects": [
    "**/*.css"
  ],
```

ところでなぜこの設定が必要なのか？理由はツリーシェイキングです。

バンドラーは依存解決の際に使っていない不要なファイルを削除します。

style.cssは使っていないからと言って消されるとスタイルが崩れます。なのでバンドラーにside effectがあるから消さないでとお願いしているようなイメージです。
