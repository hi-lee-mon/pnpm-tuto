## subpath importがなぜ使われるのか？
ツリーシェイキングがバンドラーに依存せずに行える。

## ツリーシェイキングはどうやってやるのか
バンドラーがやってくれる。
なのでライブラリ開発者ｈツリーシェイキングできる形にライブラリを作る必要がある。
* ESMにする
* side effectを適切書く
* peerDependenciesを適切に書く
* subpath importを用意する

## importしたときcjsはバンドルされるのか？
されない。つまりimportではESMだけがimportされる。

## distのチャンクファイル
tsupでbuildするとdist配下にchunkファイルが作成される。
chunkファイルは分割されたJSファイルのこと。

entry pointを見てbuildするが、このとき`複数の場所から参照できる`ものはchunkとして切り出す
```bash
tsup src/index.ts src/components/*/index.ts
```
となっているのでエントリーポイントは以下の2つになる。
```bash
dist/index.js
dist/components/button/index.js
dist/components/text-field/index.js
```
例えばbuttonはindex.jsからexportされるし、button/index.jsからもexportされる。
build結果としてそのまま出してしまうと2箇所からimportできるようになってしまう。
なのでchunkとして実装を切り出して、exportを1箇所に集める。
